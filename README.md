# Ceylonways website

Published output of a Sri Lanka trip planning prototype. Prices, stays and offers are sample data.

Data credits: imagery Sentinel-2 cloudless 2016 by EOX (CC BY 4.0), contains modified Copernicus Sentinel data.
Elevation: Copernicus DEM GLO-30. Boundaries: geoBoundaries (OpenStreetMap, ODbL).
Roads: OpenStreetMap contributors (ODbL). The route data in assets/map/routes.json is derived from
OpenStreetMap and is available under the Open Database License.
